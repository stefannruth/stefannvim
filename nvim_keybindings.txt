CORE (lua/stefan/core/keymaps.lua)
--------------------------------------------------

LaTeX / Vimtex
- n  <leader>lv  -> latex_view_in_split                         (LaTeX: compile + view in split)
- n  <leader>ll  -> :VimtexCompile<CR>
- n  <leader>lv  -> :VimtexView<CR>                              (NOTE: overrides earlier <leader>lv)

Editing / movement
- v  J           -> :m '>+1<CR>gv=gv                             (moves lines down in visual selection)
- v  K           -> :m '<-2<CR>gv=gv                             (moves lines up in visual selection)
- n  J           -> mzJ'z
- n  <C-d>       -> <C-d>zz                                      (move down centered)
- n  <C-u>       -> <C-u>zz                                      (move up centered)
- n  n           -> nzzzv
- n  N           -> Nzzzv
- v  <           -> <gv
- v  >           -> >gv

Clipboard / registers

==================================================
NOTES / CONFLICTS
==================================================

1) <leader>d is defined twice:
- core: delete without yanking
- LSP: diagnostics float
=> In LSP-attached buffers, <leader>d will likely show diagnostics float.

2) <leader>lv is defined twice in LaTeX keymaps:
- latex_view_in_split
- VimtexView
=> The later one overrides earlier.

3) You now have both Telescope and Snacks pickers:
- Telescope: <leader>pr, <leader>pWs, <leader>ths
- Snacks: <leader>pf, <leader>ps, <leader>pk, <leader>pc, <leader>pws, etc.
